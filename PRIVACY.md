# Browser Workspace Privacy Policy

Browser Workspace is a Chrome extension that manages named tab-group workspaces and reusable tab pools inside the user's browser.

## Data handling

Browser Workspace does not send, sell, share, or transfer user data to the developer or to third parties.

The extension uses Chrome's local extension storage only to keep workspace configuration and local lease metadata needed to restore and manage workspaces. This information stays in the user's browser profile.

The extension may read tab identifiers, URLs, tab-group membership, navigation-target relationships, and related browser state only as needed to create, group, navigate, reuse, release, or reclaim workspace tabs. This information is processed locally and is not transmitted to an external service.

Browser Workspace does not collect personally identifiable information, authentication information, financial information, health information, personal communications, location data, website content, or user activity for external storage or analytics.

## Remote code

Browser Workspace does not execute remote JavaScript or WebAssembly. All extension code is packaged with the extension.

## Contact

Questions about this privacy policy may be submitted through the Browser Workspace GitHub repository.
